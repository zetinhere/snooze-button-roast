One line roasting an alarm clock that rings at 6 AM on a Saturday — written by a deterministic program for make.fun's "Snooze Button Roast" bounty, $2 in USDC. The line was picked from 24 drafted candidates by a head-to-head proxy-judge tournament scored on the house judge's own criteria (unexpected turn, punchline in the last few words, fresh angle, tight enough to say in one breath).

## Run it

```sh
node main.ts
```

It writes the roast to `/output/entry.txt` (one line, under 200 characters, no network, no randomness).
